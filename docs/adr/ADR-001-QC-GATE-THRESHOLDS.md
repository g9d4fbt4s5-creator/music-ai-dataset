## 背景

音乐数据集构建过程中，需要对采集的音频进行质量检查，分为 pass / marginal / fail 三分支。
fail 不进入下游 Stage，marginal 进入下游但标记 `flag_for_review`，pass 直接放行。

阈值的设置直接影响数据质量和人工审核工作量，需要基于数据分布和人工听检结果持续调整。

---

## 决策

### 1. 三分支合并逻辑

**规则**：任一维度 fail → 最终 fail；否则任一维度 marginal → 最终 marginal；全 pass → pass。

**理由**：避免单一指标误杀优质样本（如老爵士高 DR 但低 SNR），但任一维度严重不合格（如无法解码、非音乐）必须 fail。

### 2. 内容分类 (YAMNet)

| 阈值 | 值 | 理由 |
|------|-----|------|
| music_score_pass | 0.7 | YAMNet 置信度高，直接放行 |
| music_score_fail | 0.3 | YAMNet 置信度低，判为非音乐 |
| 中间区间 | 0.3 ~ 0.7 | marginal，人工确认 |

**重要约束**：YAMNet 阈值不因为域外样本（Ace Studio 生成 + Demucs 分轨人声单轨）而调整。
这类样本应在数据采集阶段通过 `source_type` 标记排除，而非修改模型阈值。
域外样本处理参见 ADR-003《数据划分与来源隔离》。

### 3. 音质指标 (librosa)

| 指标 | fail | marginal | pass / info | 理由 |
|------|------|----------|-------------|------|
| **SNR (dB)** | < 10 | 10 ~ 12 | ≥ 12 | 原规则<15为marginal，经9首听检确认12~15dB样本全部合格，12~15dB从marginal升级为pass |
| **削波比例** | > 5% | 2% ~ 5% | ≤ 2% | 大量削波带来严重失真；少量瞬间削波允许（经验阈值，待500首验证） |
| **静音比例** | > 80% | 60% ~ 80% | ≤ 60% | 爵士/古典长前奏/间奏/尾奏正常；>80%无有效音乐内容 |
| **DR (dB)** | < 3 | 3 ~ 5 | ≥ 5；>20 仅 info | 高DR是优点（古典/爵士/原声常见），不是缺陷；低DR才是过度压缩 |
| **LUFS 集成响度** | < -36 或 > -4 | -36~-28 或 -8~-4 | -28~-8 | 音乐标准响度区间；金属/电子 -8~-4为正常母带风格，不判fail |
| **DC offset** | > 0.15 | 0.05 ~ 0.15 | < 0.05 | 直流偏移带来爆音（预留接口，v7版本考虑启用） |
| **可解码性** | corrupted=True | — | 正常 | 损坏音频直接fail |

> 阈值后抽检机制参见 ADR-002《HITL 异步闭环》。域外样本处理参见 ADR-003《数据划分与来源隔离》。

### 4. 时长

| 阈值 | 值 | 理由 |
|------|-----|------|
| duration_min_fail | 5s | <5s 碎片无音乐信息 |
| duration_long_form | 15min | >15min 标记 long_form，marginal |
| duration_dj_mix | 30min | >30min 标记 dj_mix，需分段 |

**不采用**：>720s 直接 fail。理由：会误杀长即兴爵士/古典乐章。

### 5. 源质量

| 指标 | marginal | pass / info | 理由 |
|------|----------|-------------|------|
| 采样率 | < 22050 Hz | ≥ 22050 Hz | 低采样率影响下游特征提取 |
| 比特率 | orig_bitrate < 128kbps | ≥ 128kbps | 只检查原始有损格式；FLAC无损不检查 |
| 声道 | — | mono 仅 info | 很多爵士/老录音本身就是单声道，不是质量问题 |

### 6. Stage 0 入库前硬门槛（2026-08-27 新增）

**与 Stage 0.5 QC Gate 的区别**：
- **Stage 0 入库前硬门槛**：在音频入库（分配 ULID、写入 manifest、复制到 raw_audio/）**之前**执行，不满足则直接拒绝入库，不占用存储和 ID
- **Stage 0.5 QC Gate**：入库后执行，输出 pass/marginal/fail 三分支，fail 样本逻辑排除但物理保留

**硬门槛阈值**：

| 指标 | 阈值 | 理由 |
|------|------|------|
| **最小时长** | ≥ 30 秒 | <30秒碎片无完整音乐结构，无法用于训练切片（15秒×2） |
| **最小采样率** | ≥ 16000 Hz | MERT 模型输入为 16kHz，低于此采样率无法提取有效嵌入 |
| **可解码性** | ffmpeg/ffprobe 可正常解码 | 损坏音频无法处理 |
| **文件完整性** | 文件大小 > 0 且 < 500MB | 空文件或异常大文件 |

**不满足硬门槛的处理**：
1. 不分配 ULID
2. 不写入 manifest
3. 不复制到 raw_audio/
4. 记录到 `data/00_raw_collect/rejected_imports.csv`（含原始文件名、拒绝原因、时间戳）
5. 原始文件保留在上传目录，不删除（供用户复查）

**与 Stage 0.5 QC Gate fail 的区别**：
- Stage 0 硬门槛拒绝：**从未入库**，无 ULID，无 manifest 记录
- Stage 0.5 QC fail：**已入库**，有 ULID 和 manifest，逻辑排除但物理保留

### 7. fail 样本物理隔离规则（2026-08-27 新增）

**Stage 0.5 QC Gate 判定为 fail 的样本**，必须执行物理隔离：

| 动作 | 规则 |
|------|------|
| **目录隔离** | 从 `data/00_raw_collect/raw_audio/` 移动到 `data/00_raw_collect/quarantine/`（隔离区） |
| **manifest 标记** | `qc_final_branch = fail`，`quarantined = True`，`quarantine_date = YYYY-MM-DD` |
| **下游排除** | Stage 1-6 所有脚本必须过滤 `qc_final_branch = fail` 的样本，禁止进入母版生成、特征提取、训练切片 |
| **保留期限** | 隔离区样本保留 90 天，供人工复查和误判恢复；90 天后可归档或删除 |
| **恢复机制** | 人工复查确认误判后，从 quarantine/ 移回 raw_audio/，manifest 标记 `qc_final_branch = pass`，`quarantined = False` |

**违反后果**：
- fail 样本（如 2 秒超短音频、非音乐、损坏文件）进入下游 Stage，导致：
  - L1 物理特征提取产生无效值（BPM=0、key=Unknown）
  - MERT/CLAP 嵌入提取失败或产生异常向量
  - 训练切片产生无效样本（<15秒）
  - 模型训练时损失函数异常

**当前状态**（2026-08-27）：
- 85 首母版中包含 1 首 2 秒 fail 样本（已被 L1 处理，产生 BPM=0 的无效特征）
- 需修复：将该样本移入 quarantine/，重新运行 L1/L2 排除 fail 样本
- 此问题记录为 P1 债务，待 500 首扩展前修复

## 阈值调整历史

| 日期 | 调整 | 原因 | 听检支撑 |
|------|------|------|----------|
| 2026-08-24 | SNR marginal 15→12dB | 9首marginal人工听检100%可接受（噪声为音乐制作正常特征） | 9首全检，7首SNR 13-15dB升级为pass |
| 2026-08-25 | DR >20 从 fail 改为 info | 高DR是优点，古典/爵士/原声常见；旧代码DR=184dB是计算bug | 27首中25首DR>20，全部为正常高动态录音 |
| 2026-08-25 | FLAC 比特率检查移除 | FLAC无损压缩比特率随内容动态变化，不反映源质量 | 代码修复：只检查 orig_bitrate |
| 2026-08-25 | mono 从 marginal 改为 info | 很多爵士/老录音本身就是单声道，不是质量问题 | 19首新采集jazz中多首mono，全部为正常录音 |
| 2026-08-26 | 静音 marginal 50%→60% | 爵士/古典长前奏/间奏/尾奏常见，50%会把大量合格样本打入marginal | 基于爵士乐结构分析 |
| 2026-08-26 | LUFS fail 边界 -6→-4 | 金属/电子乐常见 -8~-4 LUFS，这是母带风格不是缺陷 | 基于响度战争行业实践 |

## 工程约束

- **marginal 样本不自动删除，也不直接进训练集**：进入 marginal 候选池，人工 Label-Studio 复核后升级 pass 或标记 fail。
- **老爵士乐大量黑胶转录、现场录音会落到 marginal**：不能脚本直接过滤，防止大量有效样本丢失。
- **fail 样本不删除物理文件**：物理归档备份，仅做逻辑排除，防止误判。
- **阈值调整必须有听检支撑**：不允许凭感觉调整阈值，必须基于人工听检结果和数据分布。
- **阈值后抽检 (post_threshold_audit)**：阈值调整后，自动识别阈值漂移样本并分层抽检，劣质率>20%自动回滚。参见 ADR-002《HITL 异步闭环》。
- **数据集分布统计**：对 train/val/golden/holdout 做完整分布对比与域偏移告警；ood/marginal 仅输出独立统计报表，不参与偏移校验；fail 仅统计总量。
